# 3세 앱 그림 목록

> 4세 앱(`elephant-numbers/public/images`)에 이미 있는 그림은 "재사용"으로 표시했어요. 지금 앱은 도형+글자 자리표시라서, 그림을 넣을 때 이 표를 기준으로 해요.

## 1. 캐릭터 (모두 4세 앱 것 사용)

| 쓰는 곳 | 캐릭터 | 4세 앱 파일 | 상태 |
|---|---|---|---|
| 모든 마을 진행자 | 코끼리 | `characters/elephant.webp` | 재사용 |
| 농장 | 병아리 | `characters/chick.webp` | 재사용 |
| 농장, 위 아래 안 밖 | 토끼 | `characters/rabbit.webp` | 재사용 |
| 농장 | 돼지 | `characters/pig.webp` | 재사용 |
| 숲속 | 다람쥐 | `characters/squirrel.webp` | 재사용 |
| 숲속 (곰 대신) | 판다 | `characters/panda.webp` | 재사용 (갈색 곰은 4세 앱에 없음) |
| 숲속 (새 대신) | 부엉이 | `characters/owl.webp` | 재사용 (작은 새는 4세 앱에 없음) |
| 바닷가 | 게 | `characters/crab.webp` | 재사용 |
| 바닷가 | 거북이 | `characters/turtle.webp` | 재사용 |
| 바닷가 | 물고기 | `props/fish.webp` | 재사용 (소품 그림) |
| 크다 작다 (큰 동물) | 곰 대신 하마 | `characters/hippo.webp` | 재사용 추천 (다람쥐와 크기 차이가 커서 구별하기 쉬워요) |

새로 그려야 하는 캐릭터는 **없어요.** 갈색 곰과 작은 새가 꼭 필요하면 나중에 추가해요.

## 2. 배경

| 화면 | 4세 앱 파일 | 상태 |
|---|---|---|
| 시작, 마을 지도 | `backgrounds/savanna-base.svg` | 재사용 |
| 농장 마을 (게임 3개 공통) | `backgrounds/farm-base.svg` | 재사용 |
| 숲속 마을 (게임 3개 공통) | `backgrounds/forest-base.svg` | 재사용 |
| 바닷가 마을 (게임 3개 공통) | `backgrounds/sea-base.svg` | 재사용 (바다·극지 배경) |
| 스티커북, 보상 | `backgrounds/savanna-base.svg` | 재사용 가능 |
| **잠금 화면 (밤, 코끼리가 졸린 장면)** | 없음 | **새로 필요** |

게임마다 따로 배경은 만들지 않고 마을 배경을 같이 써요.

## 3. 보조 아이콘·소품

### 재사용

| 종류 | 이름 | 4세 앱 파일 |
|---|---|---|
| 버튼 | 시작(▶), 확인(✔), 집, 닫기, 지도, 별, 자물쇠, 설정, 스피커 | `icons/play, check, home, close, map, star, lock, settings, speaker` |
| 과일 | 사과, 바나나, 딸기 | `props/fruit-apple, fruit-banana, fruit-strawberry` |
| 소품 | 바구니, 도토리, 나무, 조개, 달걀 | `props/basket, acorn, tree, shell, egg` |

### 새로 필요

| 쓰는 곳 | 그림 | 개수 | 비고 |
|---|---|---|---|
| 모양 찾기 | 동그라미, 네모, 세모 | 3 | 색칠된 큰 도형 |
| 위 아래 안 밖 | 상자 (열린 모양) | 1 | 토끼를 위·아래·안·밖에 놓음 |
| 패턴 이어가기 | 구슬 2가지 색 (● ○ 대신) | 2 | 도형 그림 대신 CSS로 그려도 돼요 |
| 한눈에 알기, 같은 수 찾기 | 점 (주사위 같은 점) | 1 | 도형 하나를 여러 개 놓아요. CSS로 그려도 돼요 |
| 스티커 9장 | 동물 그림 재사용 | 0 | 게임 하나 끝낼 때마다 동물 스티커 1장 (새 그림 없음) |
| 시간 알림 | 하품하는 코끼리 | 1 | 없으면 코끼리 그림에 말풍선만 써도 돼요 (선택) |

**새로 그려야 하는 그림은 총 8개** (배경 1, 도형 3, 상자 1, 구슬 2, 점 1). 구슬·점을 CSS로 그리면 5개예요. 하품하는 코끼리는 선택이라 뺐어요.
