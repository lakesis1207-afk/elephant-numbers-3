# 3세 앱 새로 녹음할 음성 대사

> 4세 앱에 이미 녹음된 음성과 **같은 문장**은 뺐어요. 여기 있는 것만 새로 만들면 돼요. 지금은 브라우저 읽기로 대신 소리를 내요.
> 새로 녹음할 대사 **63줄** (선택 12줄은 따로)

## 2. 게임별 문제 안내 (45줄)

| 마을 | 게임 | 줄 수 | 대사 |
|---|---|---|---|
| 농장 | 세어 주기 | 30 | 아래 표 참고 |
| 농장 | 많다 적다 | 2 | 어느 쪽이 더 많을까? / 어느 쪽이 더 적을까? |
| 농장 | 모양 찾기 | 3 | 동그라미를 찾아 줘 / 네모를 찾아 줘 / 세모를 찾아 줘 |
| 숲속 | 크다 작다 | 2 | 큰 동물을 찾아 줘 / 작은 동물을 찾아 줘 |

| 숲속 | 한눈에 알기 | 1 | 점이 몇 개였지? |
| 바닷가 | 패턴 이어가기 | 1 | 다음에 올 것은 뭘까? |
| 바닷가 | 위 아래 안 밖 | 4 | 토끼를 상자 위에 놓아 줘 / 아래에 놓아 줘 / 안에 놓아 줘 / 밖에 놓아 줘 |
| 바닷가 | 같은 수 찾기 | 1 | 같은 수를 찾아 줘 |

### 세어 주기 (과일 3종 × 1~10개 = 30줄)

| 과일 | 대사 (개수만 바뀜) |
|---|---|
| 사과 | 사과 한 개 줄래? / 두 개 / 세 개 / 네 개 / 다섯 개 / 여섯 개 / 일곱 개 / 여덟 개 / 아홉 개 / 열 개 줄래? |
| 바나나 | 바나나 한 개 줄래? … 열 개 줄래? (같은 방식) |
| 딸기 | 딸기 한 개 줄래? … 열 개 줄래? (같은 방식) |

과일을 사과 하나로 줄이면 10줄이라 총 43줄이 돼요.

| 대사 | 4세 앱 파일 | 비고 |
|---|---|---|
| 말풍선을 누르면 다시 들을 수 있어! | `idle.mp3` | 같은 문장 |
